# Player Reporting Guide

While our automated logs and anti-cheat software constantly detect and mitigate inappropriate activities, there are times when manual reporting is necessary. Use the in-game reporting tool to report players for any of the following infractions:

* **Bug / Feature Abuse**
* **Inappropriate Name**
* **Macro Usage**
* **Unauthorized Program / Cheat**
* **Other Violations**

---

### Step 1: Accessing the Report Tool

1. Press the `ESC` key to open the main menu.
2. Use the search bar to search for **"Report"** and open the tool.

> ⚠️ **Important:** You must be physically located close to the target player within the game world at the time of submission.

![Report Tool Interface](https://i.ibb.co/WWPfbFyp/image.png)

---

### Step 2: Selecting the Target and Submitting

1. Select the offending player's name from the interface population list.
2. Specify the reason for your report and submit.

![Player Selection](https://i.ibb.co/8DGPPFvx/image.png)

---

### Review Process

All submissions generated through this dedicated tool are routed directly to the administration queue. The management team reviews these incoming data sets immediately to enforce necessary disciplinary actions.
