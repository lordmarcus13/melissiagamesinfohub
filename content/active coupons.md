## HOW TO REDEEM CODES

1. Go to [Melissia Games Office](https://office.melissia.games/)
2. Login
3. Select `Redeem Code` from right drop-down menu

![](https://i.ibb.co/FLqBV0pH/image.png)

4. Copy the code from [Active Coupons](https://discord.com/channels/906712777333288990/1421996185400377374)

![](https://i.ibb.co/pjC4Ss0X/image.png)



> *Or Copy from wherever you get the code from :event, giveaway, etc. Codes are something like `THIS-IS-A-SAMPLE-CODE` and will contain letters and numbers.*

5. Paste the code in the text box and click 

![](https://i.ibb.co/4Zw4Rm2j/image.png)

> **Remember:** You must be logged of from the game while redeeming the code.

> **Note:** You will receive items from the code in your **in-game mail**. You can access your in-game mail by pressing `B` in-game.
